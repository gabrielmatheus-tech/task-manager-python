# ✅ Lista de Tarefas em Python

Projeto de gerenciamento de tarefas feito em Python no terminal.

O sistema permite criar contas, fazer login e gerenciar tarefas de forma simples e organizada.

## 🚀 Funcionalidades

- Criar conta
- Login de usuário
- Criar tarefas
- Marcar tarefas como concluídas
- Editar tarefas
- Remover tarefas
- Logout
- Interface no terminal

## 🛠️ Tecnologias utilizadas

- Python
- Dicionários
- Listas
- Funções
- Loops
- Condicionais

## 📚 Aprendizados

Neste projeto pratiquei:

- Manipulação de listas e dicionários
- Organização de código
- Estruturação de menus
- CRUD em Python
- Sistema de autenticação
- Manipulação de índices
- Tratamento de tarefas concluídas

```bash
python main.py
